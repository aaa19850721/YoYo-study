# SPEC：语法卡片例句编写规范

为每个语法大类编写 **3 个例句**，要求：

1. **难度**：小学英语水平（1-6 年级）。每句 ≤10 个单词，用最基础的词汇（红火箭分级阅读风格：日常名词、常见动词）。
2. **贴合语法点**：每句必须**典型地体现该语法大类的用法**（例如「一般现在时——第三人称单数」的句子动词要加 -s）。如果一个卡片涵盖多个子要点（如名词复数的 -s/-es/不规则），3 句尽量覆盖不同子要点。
3. **句式多样**：3 句不要同一主语开头、不要同一句型结构；可以包含陈述句、疑问句、否定句的变化（如该语法允许）。
4. **正确自然**：语法必须完全正确，符合小学生能读懂的语境（动物、家庭、学校、游戏、食物等场景）。
5. **格式**：每句以大写字母开头，以句号/问号/感叹号结尾；不用中文、不用引号包裹整句。
6. **输出**：JSON 对象，键=语法大类名（与输入的 name 完全一致），值=字符串数组（恰好 3 个例句）。
